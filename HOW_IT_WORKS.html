1. Executive Overview

Pruwear is an intelligent browser extension that transforms any modern web browser into a live, interactive virtual fitting mirror. Designed for zero-friction consumer shopping, it operates seamlessly across major fashion e-commerce platforms (such as Zara, Myntra, ASOS, H&M, Amazon, Shopify, and bespoke brand boutiques).

Shoppers can drag any product photograph from an online catalog directly into their personal fitting mirror, where high-speed neural synthesis models project and drape the chosen garment onto their live body contours in real time.

2. End-to-End Operational Workflow

The system coordinates five real-time stages to achieve sub-second fitting feedback:

Stage 1
Non-Invasive Discovery & Shadow DOM Encapsulation

When a shopper lands on an e-commerce page, a lightweight content script initializes in document_idle mode. All UI components (floating dock and contextual try-on badges) are attached inside a sealed Shadow DOM container (pruwear-root). This ensures 100% style isolation, preventing store styling conflicts and avoiding React hydration collisions on dynamic single-page applications (Next.js, Remix, Vue).

Stage 2
Intelligent Resolution Escalation & Asset Extraction

E-commerce CDNs aggressively downsample images for web efficiency. When an item is dragged:

  • Attribute Scanning: The parser examines data-zoom-image, data-old-hires, and dynamic responsive srcset arrays to bypass compressed thumbnails and extract uncompressed master catalog images.
  • Metadata Resolution: If a product link or card is dragged, the extension's background service worker resolves OpenGraph tags (og:image, twitter:image) to recover the primary clothing article automatically.
Stage 3
Client-Side Pose Tracking & Alignment Guidance

When the user activates their webcam, an in-browser computer vision engine running directly via WebAssembly (WASM) analyzes the stream:

  • Zero Server Latency: Body landmark detection and torso segmentation happen completely client-side without transmitting raw frames to the cloud for tracking.
  • Interactive Framing Guide: Guides the user to optimal distance and posture, ensuring garments are projected with anatomical precision.
Stage 4
Neural Virtual Try-On Synthesis

Once alignment is confirmed, the neural try-on synthesis pipeline takes over:

  • 3D Volume Mapping: 2D flat garments are warped onto the 3D volume of the user's posture, simulating fabric tension, folds, and natural drapery.
  • Photometric Harmonization: Ambient lighting, room shadow angles, and skin-tone transitions are balanced dynamically.
  • Real-Time Video Delivery: Delivers continuous live video streaming over low-latency WebRTC, allowing the user to turn, step back, and move naturally.
Stage 5
Multi-Garment Comparison & History

Users can drag and swap multiple garments sequentially to compare combinations, colors, and cuts side-by-side before reaching a checkout decision.

3. Privacy, Isolation & Security Design

Camera & Data Isolation

The webcam feed never touches the host retail webpage. All camera access is isolated strictly to the extension's private internal origin (tabs/room.html). Retailers cannot record, intercept, or inspect the user's camera stream.

Furthermore, strict Content Security Policies (CSP) enforced by retail or banking sites cannot block the fitting room, as all WebRTC streaming and WebAssembly tasks run in the extension's sandboxed environment.
