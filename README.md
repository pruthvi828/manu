# MANU — AI Voice Studio

> Luxury glassmorphism UI for pasting API keys and recording voice.

![preview](https://img.shields.io/badge/UI-Glassmorphism-blueviolet?style=for-the-badge)
![status](https://img.shields.io/badge/Status-Working-brightgreen?style=for-the-badge)

## ✦ Features

| Feature | Description |
|---------|-------------|
| **API Key Paste** | One-click paste from clipboard, show/hide toggle, local secure storage |
| **Voice Recorder** | Real-time audio recording with live frequency visualizer ring |
| **Glassmorphism UI** | Frosted glass cards, animated gradient mesh, mirror shine effects |
| **Download** | Instant playback + download of recorded audio |
| **Keyboard Shortcut** | Press `Space` to start / stop recording |

## ✦ Getting Started

```bash
# No build step required — just open index.html
# Or serve locally:
npx serve .
```

## ✦ Tech Stack

- **Vanilla HTML / CSS / JS** — zero dependencies
- CSS `backdrop-filter` glassmorphism
- Web Audio API + Canvas 2D for the live visualizer
- MediaRecorder API for audio capture
- LocalStorage for key persistence
